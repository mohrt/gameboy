Game Boy boot ROMs

None is needed: games start as the boot ROM would leave them. With one, the console starts in it as the real one does, showing the Nintendo logo before the game; the Color's also chooses the colours for original Game Boy games. The boot ROMs are Nintendo's and still under copyright, so none is included: choose or drop your own. They stay in this browser and are never sent anywhere.

  • Game Boy boot ROM Optional

    Starts the original Game Boy, and is the Game Boy Pocket's too. Exactly 256 bytes.

    Often named dmg_boot.bin, dmg_rom.bin or DMG_ROM.bin

  • Game Boy Color boot ROM Optional

    Starts the Game Boy Color, and chooses the colours for original Game Boy games. Exactly 2,304 bytes.

    Often named cgb_boot.bin, gbc_bios.bin or CGB_ROM.bin

The retrobios collection keeps Nintendo's as dmg_rom.bin in its Game Boy folder and gbc_bios.bin in its Game Boy Color folder.
